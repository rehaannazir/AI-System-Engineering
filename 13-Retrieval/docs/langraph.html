LangGraph

1. What It Is

LangGraph is a low-level orchestration library, built by the LangChain team, for constructing stateful, multi-actor applications as a graph of nodes and edges. It was released in January 2024 to address workflows that plain LCEL chains cannot express: loops, branching, and persistent state.

2. Core Concepts

2.1 State

A shared, typed object (often a TypedDict or Pydantic model) that is passed between nodes and updated as the graph executes. Each node returns a partial update that is merged into the global state.

2.2 Nodes

Python functions (or Runnables) that receive the current state and return an updated state. A node can call an LLM, a tool, or arbitrary code.

2.3 Edges

  • Normal edges — always move from node A to node B
  • Conditional edges — a routing function decides the next node, enabling branching and cycles

2.4 Graph Types

StateGraph is the primary graph builder. Two required special nodes are START and END, which mark entry and termination points of execution.

3. Persistence and Checkpoints

LangGraph ships a checkpointer (e.g. MemorySaver, SqliteSaver, PostgresSaver) that snapshots state after every super-step. This enables:

  • Resuming execution after a crash
  • Time-travel debugging (rewind to a prior checkpoint)
  • Human-in-the-loop interrupts before a sensitive node runs

4. Multi-Agent Patterns

5. LangGraph vs. LangChain Chains

Plain LCEL chains are directed acyclic graphs (DAGs) executed once, top to bottom. LangGraph explicitly supports cycles, making it suited for agent loops that must re-plan, retry, or wait on human approval before continuing.

6. Deployment

LangGraph Platform (formerly LangGraph Cloud) provides one-click deployment, a hosted API, and LangGraph Studio, a visual debugger for inspecting graph runs step by step.
